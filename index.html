Semáforo Sonoro de Acessibilidade

Projeto desenvolvido com Arduino Uno, Módulo Semáforo e Buzzer na Protoboard

Simulador Sonoro Interativo

Clique nos botões para ouvir a simulação exata da sequência sonora emitida pelo buzzer do Arduino:

Sinal Vermelho

3 Bipes

Indica parada obrigatória para pedestres.

Sinal Amarelo

2 Bipes

Alerta de mudança do sinal.

Sinal Verde

1 Bipe

Permissão para atravessar com segurança.

1. Componentes e Montagem do Circuito

O circuito foi construído utilizando um módulo pré-montado de semáforo e um buzzer instalado em uma protoboard para organização dos cabos:

  • Arduino Uno: Placa responsável pelo processamento do programa e temporização.
  • Módulo Semáforo (Placa Pronta): Contém os LEDs Vermelho, Amarelo e Verde integrados com resistores embutidos.
  • Protoboard: Matriz de contatos usada para fixar o Buzzer Piezoelétrico.
  • Buzzer Piezoelétrico: Emitir o sinal sonoro de acessibilidade.
  • Jumpers: Fios de conexão ligando os módulos às portas do Arduino.

2. Código-Fonte C++ (Para VS Code / PlatformIO)

Código carregado no Arduino Uno para gerenciar a temporização e o número de bipes:

#include <Arduino.h>

// Mapeamento dos Pinos
const int PIN_VERMELHO = 10;
const int PIN_AMARELO  = 9;
const int PIN_VERDE    = 8;
const int PIN_BUZZER   = 6;

// Função para emitir 1 bipe curto (1000 Hz)
void emitirBipe() {
  tone(PIN_BUZZER, 1000); 
  delay(150);             
  noTone(PIN_BUZZER);     
  delay(200);             
}

// Emite N bipes sequenciais
void apitar(int quantidade) {
  for (int i = 0; i < quantidade; i++) {
    emitirBipe();
  }
}

void setup() {
  pinMode(PIN_VERMELHO, OUTPUT);
  pinMode(PIN_AMARELO, OUTPUT);
  pinMode(PIN_VERDE, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);
}

void loop() {
  // 1. VERMELHO: 3 bipes
  digitalWrite(PIN_VERMELHO, HIGH);
  digitalWrite(PIN_AMARELO, LOW);
  digitalWrite(PIN_VERDE, LOW);
  apitar(3);
  delay(4000);

  // 2. AMARELO: 2 bipes
  digitalWrite(PIN_VERMELHO, LOW);
  digitalWrite(PIN_AMARELO, HIGH);
  digitalWrite(PIN_VERDE, LOW);
  apitar(2);
  delay(2000);

  // 3. VERDE: 1 bipe
  digitalWrite(PIN_VERMELHO, LOW);
  digitalWrite(PIN_AMARELO, LOW);
  digitalWrite(PIN_VERDE, HIGH);
  apitar(1);
  delay(4000);
}
